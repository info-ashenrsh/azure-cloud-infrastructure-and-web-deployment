# Practical activity — Cloud monitoring

## Steps
1. Open an existing Azure lab resource.
2. Inspect its Metrics view.
3. Choose a time range and identify a metric.
4. Read the Azure Monitor overview.
5. Read the Application Insights overview.
6. When CloudTask is deployed, enable only the telemetry needed and inspect requests and exceptions.

## Completion checklist
- [ ] I can explain metrics versus logs.
- [ ] I inspected at least one resource metric.
- [ ] I understand what Application Insights tracks.
- [ ] I considered monitoring ingestion and retention cost.
