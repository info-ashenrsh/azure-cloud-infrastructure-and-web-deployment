# Practical activity — Virtual networking

## Objective
Map the network path between browser, web application, database, and storage.

## Steps
1. Draw the components and label each connection.
2. Identify which traffic is inbound and outbound.
3. Label HTTPS 443 and PostgreSQL 5432 where applicable.
4. Inspect the Networking blade of your existing VM.
5. Review NSG rules and identify any overly broad access.
6. Do not change production or shared network rules without understanding impact.

## Completion checklist
- [ ] I can explain VNet and subnet.
- [ ] I can explain public/private IP and DNS.
- [ ] I can explain an NSG rule.
- [ ] I understand private endpoint versus VNet integration.
