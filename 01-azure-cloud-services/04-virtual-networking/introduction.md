# Virtual networking — introduction

A Virtual Network (VNet) is an isolated network address space in Azure. Subnets divide the address space into smaller ranges.

Learn:
- IPv4 address and CIDR notation.
- Public and private IP addresses.
- Subnets and routing.
- DNS name resolution.
- Network Security Groups (NSGs).
- Inbound and outbound traffic.
- Private endpoints and VNet integration.

A VNet alone does not make every PaaS resource private. Each service has its own network integration and DNS requirements.
