# Azure Blob Storage

## Create a private test container

1. Open your Storage Account.
2. Under **Data storage**, select **Containers**.
3. Select **+ Container**.
4. Name it `task-files`.
5. Set anonymous access level to **Private (no anonymous access)**.
6. Create the container.
7. Upload a small, non-sensitive sample text file.
8. Verify that anonymous access is not allowed.

Portal labels may change. If using a student subscription, check storage cost before creation.

## Evidence
- [ ] Private container exists.
- [ ] Sample file uploaded.
- [ ] Access level is private.
- [ ] Screenshot contains no keys or sensitive data.
