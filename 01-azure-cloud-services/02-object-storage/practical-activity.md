# Practical activity — Object storage

## Objective
Create and test a private Blob container.

## Steps
Follow `azure-blob-storage.md`. Upload a harmless text file such as `hello-cloud.txt`. Download it through the authenticated portal and compare its contents.

## Verification
Confirm the container is private and the file can be accessed by an authorized identity.

## Completion checklist
- [ ] I can explain account, container, and blob.
- [ ] I created or inspected a Storage Account.
- [ ] I created a private container.
- [ ] I uploaded and downloaded a test file.
- [ ] I documented cost and access controls.
