# Practical activity — Managed databases

## Objective
Understand managed PostgreSQL and connect an application to a database.

## Beginner sequence
1. Practise SQL locally or with a local PostgreSQL installation first.
2. Read the Azure PostgreSQL service page and pricing.
3. Check quota and region availability.
4. Create a small development server only if affordable and approved.
5. Create a database and a restricted application user.
6. Configure the app's `DATABASE_URL` outside source control.
7. Test a read/write operation from the app environment.

## Completion checklist
- [ ] I can explain server versus database versus table.
- [ ] I ran basic SQL.
- [ ] I understand TLS and firewall/private networking.
- [ ] I connected the application without committing credentials.
