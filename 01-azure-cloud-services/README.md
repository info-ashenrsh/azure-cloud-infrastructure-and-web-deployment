# Activity 01 — Explore Azure Cloud Services

Explore the six service areas in order: compute, object storage, managed databases, virtual networking, IAM/RBAC, and monitoring.

For every activity:
1. Read the introduction.
2. Check prerequisites, cost, and quota.
3. Follow the portal steps.
4. Verify the result.
5. Capture a redacted screenshot.
6. Complete the GitHub evidence checklist.
