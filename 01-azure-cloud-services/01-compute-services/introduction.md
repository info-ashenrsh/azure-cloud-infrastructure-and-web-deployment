# Compute services — introduction

Compute services provide processing power to run applications.

- **Azure Virtual Machines (IaaS):** you manage the operating system, updates, packages, and much of the server configuration.
- **Azure App Service (PaaS):** Azure manages more of the hosting platform; you focus on application code and configuration.

## Why use them?

Use a VM when you need operating-system-level control or want to practise Linux administration. Use App Service when you want a managed web-app hosting platform.

## Key terms

VM size, vCPU, RAM, disk, image, operating system, App Service plan, runtime stack, scale, and region.

## Cost

VM compute can incur charges while running; disks and some networking resources may continue to cost money when the VM is stopped. App Service plan cost depends on its tier and duration. Check the portal estimate before creating anything.
