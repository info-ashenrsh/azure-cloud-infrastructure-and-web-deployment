# Azure App Service

App Service is a managed platform for hosting web applications.

## Portal exploration

1. In Azure Portal, search **App Services**.
2. Open the create wizard only if you intend to provision a resource.
3. Inspect the available operating system, runtime, region, and App Service plan choices.
4. Review the estimated cost before selecting **Create**.
5. For this project, the intended runtime is Python on Linux.

## VM versus App Service

| Virtual Machine | App Service |
|---|---|
| You manage the OS | Azure manages the hosting platform |
| More OS control | Focus on application code |
| SSH/admin access commonly used | App deployment and app settings |
| VM size and disks matter | App Service plan tier matters |
