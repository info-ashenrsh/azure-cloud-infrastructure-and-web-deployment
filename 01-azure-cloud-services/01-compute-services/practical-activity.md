# Practical activity — Compute services

## Objective
Understand the difference between IaaS and PaaS and inspect Azure compute options.

## Steps
1. Inspect your existing Linux VM in the portal.
2. Connect through SSH if available.
3. Run the Linux information commands in `azure-virtual-machine.md`.
4. Open the App Service creation wizard and inspect options without creating a resource.
5. Compare management responsibility, use cases, and cost.

## Completion checklist
- [ ] I can explain IaaS and PaaS.
- [ ] I inspected my VM configuration.
- [ ] I understand App Service plans.
- [ ] I checked cost before provisioning.
- [ ] I added a short summary and redacted screenshots to GitHub.
