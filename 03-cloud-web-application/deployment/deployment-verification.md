# Deployment verification

- [ ] App Service is running.
- [ ] The site opens over HTTPS.
- [ ] `/health` returns `{"status":"ok"}`.
- [ ] A task can be created and listed.
- [ ] Task status can be updated.
- [ ] A task can be deleted.
- [ ] Data persists in the configured database.
- [ ] Blob upload works after implementing the integration.
- [ ] Blob container remains private.
- [ ] Application logs can be inspected.
- [ ] No secrets appear in source code or logs.
- [ ] Cost and cleanup actions are documented.
