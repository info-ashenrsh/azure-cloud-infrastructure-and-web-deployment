# Activity 03 — Deploy CloudTask

CloudTask is a small task manager used to practise the application-to-cloud-service flow.

## Features in this starter
- Add tasks.
- List tasks.
- Update task status.
- Delete tasks.
- Health endpoint.
- SQLite for local development.
- PostgreSQL support through `DATABASE_URL`.

## Cloud integration learning
The repository includes instructions for Azure Blob Storage and Key Vault. Those integrations are learning steps and are not represented as completed features in this initial application. Follow the guides and implement/test them before claiming the app uses them.

## Run locally
Follow the root README. The app defaults to SQLite and does not require Azure resources.
