# Learning outcomes

After completing the project, you should be able to explain and demonstrate:

- Azure compute options and the difference between VM and App Service.
- Object storage concepts using Azure Blob Storage.
- Managed relational databases and PostgreSQL connectivity.
- VNets, subnets, IP addressing, DNS, NSGs, and private connectivity concepts.
- Microsoft Entra ID, RBAC, managed identities, and least privilege.
- Azure Monitor and Application Insights basics.
- Environment variables and application configuration.
- Azure Key Vault and secure secret access.
- Python application logging and basic troubleshooting.
- Subscription quotas and cost awareness.
- A simple Flask application deployed to Azure with database and storage integration.

Record only outcomes you have actually demonstrated.
