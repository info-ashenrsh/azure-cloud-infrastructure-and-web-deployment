# Project roadmap

Complete the stages in order. Each stage has a practical task and evidence checklist.

| Stage | Focus | Evidence |
|---|---|---|
| 1 | Compute services | Compare VM and App Service; inspect existing VM |
| 2 | Object storage | Private Blob container and test file |
| 3 | Managed databases | PostgreSQL concepts and a verified connection |
| 4 | Virtual networking | Network diagram and verified access paths |
| 5 | IAM and RBAC | Role and managed identity review |
| 6 | Cloud monitoring | Metrics, logs, and a basic alert concept |
| 7 | Environment variables | Local `.env` and Azure app settings |
| 8 | Secrets management | Key Vault and managed identity access |
| 9 | Logging and quotas | Controlled log event and quota review |
| 10 | CloudTask deployment | Live app and verified database/storage integration |

**Beginner rule:** Do not create every Azure service at once. Learn the concept, check cost and quota, then perform one small activity. Use local development until you are ready for the cloud resource.
