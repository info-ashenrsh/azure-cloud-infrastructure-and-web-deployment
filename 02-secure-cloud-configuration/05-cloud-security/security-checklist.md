# Security checklist

- [ ] `.env` is excluded from Git.
- [ ] No credentials or keys appear in repository history.
- [ ] Blob container is private.
- [ ] Application uses HTTPS.
- [ ] Database connection uses TLS.
- [ ] Database access is restricted.
- [ ] App uses managed identity where supported.
- [ ] RBAC follows least privilege.
- [ ] Key Vault access is restricted.
- [ ] Logs do not contain secrets or personal data.
- [ ] Screenshots are redacted.
