# Azure subscription quotas

In Azure Portal:
1. Search **Subscriptions** and select your student subscription.
2. Open **Usage + quotas** (or the current equivalent).
3. Choose the relevant provider/category.
4. Select the region if applicable.
5. Compare current usage with the limit.
6. Record the requested resource/SKU and any restriction.

Do not publish subscription IDs or tenant identifiers in screenshots.
