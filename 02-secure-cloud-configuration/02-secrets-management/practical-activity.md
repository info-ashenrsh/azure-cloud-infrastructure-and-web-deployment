# Practical activity — Secrets management

## Objective
Understand how an app can access a secret without embedding it in source code.

## Steps
Follow the Key Vault and managed identity guides. Use a non-sensitive sample value for the first exercise. Confirm access is authorized, then confirm unauthorized identities cannot read it.

## Completion checklist
- [ ] I can identify common secrets.
- [ ] I understand why secrets do not belong in Git.
- [ ] I understand Key Vault and managed identity.
- [ ] I tested access without revealing the value.
