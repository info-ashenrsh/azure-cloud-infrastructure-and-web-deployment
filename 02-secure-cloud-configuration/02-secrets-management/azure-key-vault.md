# Azure Key Vault

Key Vault stores secrets, keys, and certificates.

Beginner activity:
1. Review Key Vault pricing and region availability.
2. Create a vault only if you have approval and understand soft-delete and purge-protection behavior.
3. Add a harmless training secret, not a real production credential.
4. Review the vault's access configuration.
5. Do not include the secret value in screenshots or GitHub.

Key Vault operations and associated features may incur costs.
