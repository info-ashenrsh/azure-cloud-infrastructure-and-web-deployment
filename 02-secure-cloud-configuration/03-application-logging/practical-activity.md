# Practical activity — Application logging

1. Run CloudTask locally.
2. Inspect console output.
3. Add one INFO event and one controlled WARNING event.
4. Trigger a safe validation error, such as submitting an empty title.
5. Confirm that the app responds with a useful error and does not expose a stack trace or secret.
6. When deployed, inspect App Service logs.

Checklist:
- [ ] I can explain log levels.
- [ ] I generated and inspected application logs.
- [ ] I verified secrets are not logged.
